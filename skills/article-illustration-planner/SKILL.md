# Article Illustration Planner (文章配图规划与插图回填)

深度分析文章结构与认知流转，精准规划高质量插图方案，并交付完成排版与文字修剪的最终图文定稿。

---

## 核心设计哲学：体裁自适应与认知降负

在规划任何插图之前，Skill 必须首先判断文章体裁，并自动适配两套截然不同的工作模式：

### 模式 A：知识 / 干货 / 教程 / 实操类文章 (Knowledge & Explanatory Articles)
> **核心使命：认知降负（Cognitive Load Reduction）与文字替换（Text Replacement）**

1. **配图的核心使命是“辅助理解、减轻读者负担”**：
   - 知识类文章的最大痛点是枯燥冗长的机制推演、层级漏斗、公式算法与多分支逻辑。
   - **配图决不能是脱离业务的童话叙事、抒情小品或无意义的生活杂物堆叠**（严禁无目的地画真实办公桌、咖啡杯、盆栽、窗外高楼等无关环境背景干扰知识传递）。
   - 配图必须是**高信息密度的图解（High-Information Diagram）**：层级金字塔、流向决策树、正反解剖对比图、核心架构流程图。
2. **文字替换与精炼原则（强制执行，对原文进行精炼修改）**：
   - **记住是替换，不是纯塞图**！识别文章中纯文字表达吃力、多层嵌套、读者理解成本极高的段落，由图片直观承载其复杂性；
   - 在生成最终图文定稿时，**必须将原文中被图片替代的繁冗复杂文字直接精简修剪**，替换为“见图示直观分解 + 极简核心行动清单”，真正实现“一图胜千言，大幅削减阅读疲劳”。
3. **点位排布三大铁律（防堆叠、控间距、全篇均衡）**：
   - **铁律一：开篇禁区（Opening Forbidden Zones）**：严禁在目录（Table of Contents）、前言（Lead/Preface）与第一章标题之间插入图片！读者尚未接触实质知识时插图毫无认知价值。第一张图最早只能出现在第一章核心概念阐述之后。
   - **铁律二：最小物理间距约束（Minimum Separation Distance）**：相邻两张插图之间，**正文间隔严禁少于 400 字（或约 25~35 行正文）**，且必须至少跨越一个完整的逻辑小节。严禁在同一小节或同一标题下连续插图！
   - **铁律三：全篇空间均衡分布（Balanced Global Distribution）**：配图必须均匀分布在【前部核心原理】、【中部落地SOP/操作方法】、【后部决策/诊断/闭环】，彻底杜绝“前密后空/头重脚轻”。

---

### 模式 B：非知识类文章（抒情散文、叙事故事、随笔、小说等） (Non-Knowledge Articles)
> **核心使命：意境烘托、情绪共鸣与视觉停顿 (Atmospheric Resonance & Visual Pauses)**

1. **保留原文不删改（Preserve Mode）**：不强求替换或删改原文文字，完整保留作者叙事与文风；
2. **风格可保持现有艺术探索**：可自由使用叙事微距、诗意隐喻、跨媒介微缩摄影等视觉风格，重点在于烘托情绪、营造意境与提供阅读节奏中的视觉呼吸感；
3. **点位遵循自然叙事转折**：选择在情绪转换、场景切换、时空跨越处插入。

## 知识类文章的高认知负荷段落扫描库 (5 大图替繁文场景)

当处理知识类文章时，Skill 必须主动在文章中检索并锚定以下 5 类最具“图替繁文”价值的段落：

| 高认知负荷类型 | 原文典型特征 | 对应的图示类型 (Image Type) | 图解视觉构思与替换效果 |
| :--- | :--- | :--- | :--- |
| **1. 算法与加权数学模型** | 包含加权公式、乘数权重、多指标综合计分 | `conceptual diagram` (概念架构图) | 图解维度权重天平或综合漏斗，替代繁复的数学文字推导。 |
| **2. 阶梯跃迁与分层漏斗** | 阶梯池晋级、用户生命周期阶段、长篇 ASCII 方块 | `process diagram` (流程阶梯图) | 图解阶梯金字塔与晋级门槛，**直接删除原篇 ASCII 方块**。 |
| **3. 工业化 SOP 与协作管线** | 多步骤执行时序、上下游协作闭环、时间线 | `process diagram` (流转流程图) | 图解环形或线性流动闭环，替代大段步骤文字描述。 |
| **4. 结构解剖与正反案例对照** | 爆款 vs 败笔对比、痛点反差、构图黄金法则 | `comparison diagram` (对比解剖图) | 左右分栏解剖对比（左败笔 vs 右标杆），替代抽象的排版规则说教。 |
| **5. 多分支决策树与诊断排错** | 4+ 分支条件判断（若A则...若B则...）、SOP处方 | `process diagram` (决策流转树) | 图解分支分流与执行动作，**直接删除复杂的多层嵌套列表**。 |

## 输入参数与配置规范

1. **文章内容或本地路径**：直接粘贴正文，或提供本地路径（如 `D:\path\to\article.md`）。
2. **手绘风格与色彩基调**：
   - 风格编号：全库 `#001`–`#325`；
   - 主题色编号：全库 `C-01`–`C-36`；
   - 动态研判：若未指定，由 AI 结合文章语境动态推荐一套贯穿全篇的单一风格与单色调（严禁全篇风格杂乱）。
3. **画幅比例 (Aspect Ratio)**：
   - **默认 4:3**（长文横向阅读流标准）；支持 `16:9`、`1:1`、`3:4`。
4. **留白控制 (Whitespace)**：
   - **正常 (Normal)**：标准信息密度；
   - **适中 (Moderate)**：追加 `【大量留白】`；
   - **多 (High)**：追加 `【大量留白，场景只显示必要部分，不要显示全】`。

## 标准规划方案输出模板 (Output Format)

首先出具总体设计决策：
* **文章类型判定**：知识类 / 教程类 / 散文抒情类 / 叙事故事类
* **适配工作模式**：模式 A（认知降负与文字替换） / 模式 B（意境烘托与保全模式）
* **全篇统领视觉规范**：手绘风格编号及名称、主题色编号及名称、统一画幅比例（`4:3`）、留白设置
* **建议配图总数**：通常 2~4 张高价值点位（宁缺毋滥，拒绝堆叠）

接着按阅读顺序出具每张插图规划：

```markdown
### Illustration N

**插入/替换位置 / Anchor:**
`[引用紧邻的小标题或上下文关键句（10-20字）]`

**配图定位 / Purpose:**
解释该图在阅读流中的认知价值与承接逻辑。

**图片类型 / Image Type:**
conceptual diagram / process diagram / comparison diagram / editorial illustration

**图文关系 / Relationship to Text:**
replaces complex text (文字替换与认知降负) / supplements text (内容补充) / visual-pause (视觉停顿)

**（若为文字替换）被图片替代的原繁冗文本 / Text to Replace:**
> [明确摘录原文中将被该图替代并删除的复杂推演、长篇ASCII图表或嵌套列表片段]

**（若为文字替换）精炼后的轻量导读 / Simplified Replacement Text:**
[文字替换后在 Markdown 正文中保留的极简核心要点/行动清单，通常为 1-3 句话]

**视觉构思 / Visual Concept:**
描述清晰的图解架构（包含哪些层级、分栏、箭头、标注、对比关系）。要求画面主体聚焦业务逻辑本身，背景干净，杜绝无关桌面与环境杂物。

**画风与配色 / Style & Color:**
`#{style_number} · {style_name}` + `{color_id} · {color_name}`

**生图提示词 (Prompt):**
- **中文提示词**:
```text
图片类型：{image_type}。{visual_concept}。{whitespace_clause}画风：{style_prompt}。色彩：{color_prompt}。画幅比例 4:3。
```
- **English Prompt**:
```text
Image type: {image_type}. {visual_concept_en}. {whitespace_clause_en} Style: {style_prompt_en}. Color palette: {color_prompt_en}. Aspect ratio: 4:3.
```
```

规划出具后，必须出具标准化双轨交付引导：

```markdown

💡 **插图方案已规划完成！接下来您可以选择以下两种交付方式：**

1. **【方式 A · 自主生图回填】**：
   复制上方提示词，前往您常用的生图工具出图。生成完成后，将图片文件直接拖入对话或发送本地图片路径，我将自动帮您精简替换原文繁冗文字，输出完整的图文定稿！

2. **【方式 B · 全自动生图插入】**：
   直接对我说 **“全自动生图”** 或 **“帮我生成所有配图并插入”**，我将全自动调用生图工具批量绘制配图，自动执行文字替换与排版回填，一键输出排版完毕的 Markdown 定稿文件！
```

## 双轨自动化回填工作流 (Dual-Track Assembly)

当用户触发回填时：
1. **自动组织资源**：将图片规范命名保存为 `<article_dir>/images/illus_01.webp`（或 `.png`）；
2. **执行图文装配与文字替换**：
   - 知识类文章若定义了 `Text to Replace`：自动将原文对应的复杂繁琐文字**删除修剪**，替换为 `![插图](images/illus_0N.webp)` + `*▲ 图N：说明*` + `[精炼导读/行动清单]`；
   - 若未定义文字替换：规范将图片插入指定锚点之后；
3. **输出定稿**：生成 `[article_name]_illustrated.md`。

亦可调用内置确定性自动化脚本完成：
```bash
python -X utf8 skills/article-illustration-planner/scripts/insert_illustrations.py \
  --article "D:\path\to\article.md" \
  --manifest "D:\path\to\manifest.json" \
  --output "D:\path\to\article_illustrated.md"
```
